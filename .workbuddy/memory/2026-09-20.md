## 用户反馈与功能增强：浏览器采集静默化

**背景**：post 模式改走 CDP 浏览器采集兜底后，用户截图确认流程已生效（弹出"DRaccoon 作品采集"窗口并提示"改用浏览器窗口采集作品"），但希望改成静默采集：隐藏浏览器窗口、自动滚动到底、自动关闭。

**已有能力**：
- 自动滚动到底：main.js `collectUserWorksViaBrowser` 已循环滚动至 `domStable >= idleRounds && countStable >= idleRounds`（默认 8 轮稳定后停止），已会滑到最底/无新内容。
- 自动关闭：同函数末尾调用 `cleanup()` 销毁窗口，正常结束即关闭。
- 静默模式：仅通过环境变量 `DOUZY_HIDE_COLLECT_WINDOW=1` 控制，未与 `browser_fallback.headless` 配置打通。

**本次改动**：
1. `api_client.py`：`_collect_via_electron_bridge` 增加 `headless: bool = False` 参数，并入 `/v1/browser-collect` payload；`collect_user_post_ids_via_browser` 把该参数传入。
2. `main.js`：
   - `/v1/browser-collect` 处理时把 `payload.headless` 传给 `collectUserWorksViaBrowser`。
   - `collectUserWorksViaBrowser` 优先使用 `opts.headless` 控制窗口显隐，未显式设置时回退到 `DOUZY_HIDE_COLLECT_WINDOW`。

**使用方法**：在配置里设置 `browser_fallback.headless: true`（或在设置界面开启浏览器兜底的无头模式），post 模式的 Electron CDP 采集窗口就会隐藏运行；仍保留默认可见模式以保证成功率。

**风险提示**：隐藏窗口常因不渲染/不触发懒加载导致 CDP 拦截不到 `aweme/post` 响应（main.js 历史注释）。开启静默模式后若采集失败，可改回 `headless: false` 用可见窗口。

**验证**：`py_compile`（api_client.py）与 `node --check`（main.js）均通过。

**生效前提**：彻底退出 DRaccoon 托盘进程后重开。

## 第二十三次：browser-collect "Network.enable 失败: target closed" 根因修复

**现象**：用户反馈"我的喜欢还是获取不到"。日志铁证：`[bridge] browser-collect secUid= kind=post silent=false ok=false ids=0 error=Network.enable 失败: target closed while handling command`（post/like/detail 三处均稳定复现）。

**根因（确定性）**：`collectUserWorksViaBrowser` 与 `collectAwemeDetailViaBrowser` 旧顺序为
`dbg.attach('1.3')` → `Network.enable` → `loadURL(targetUrl)`。在刚创建的 `about:blank` 目标上
attach 后、`loadURL` 触发渲染目标被替换/回收，导致紧接着的 `Network.enable` 抛 `target closed`，
CDP 拦截全程失效，post/like/detail 全部 `ids=0`。

**修复**：改为「先导航、后 attach」——`session.cookies.set` 注入登录态 → `loadURL`（目标存活）
→ `dbg.attach('1.3')` → `Network.enable`。首屏接口即便被 CDP 错过，也由末尾「页内 React props / SSR 直读」兜底（两函数本就带该兜底）。
附加：滚动停止条件由 `count>0 && 稳定` 放宽为「页面高度+数量连续稳定即停」，避免单页账号空转 ~10 分钟到 deadline；两函数加 `writeMainLog('调试器已 attach 且 Network.enable ok')` 便于确认生效。

**说明**：`secUid=` 为空时 `resolveSelfSecUid()` 已正确触发（日志已进到 Network.enable，说明 self sec_uid 解析成功），本轮不再报"缺少 secUid"。

**遗留**：collect/mix/music/favorite 模式仍走失效的「页面通道」(/v1/browser-fetch，恒 403)，各自补 CDP 采集器仍未做。

**验证**：`node --check` 通过。**生效前提**：彻底退出托盘重开。
