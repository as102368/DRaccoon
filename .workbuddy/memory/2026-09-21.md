## 二十二次：静默采集重构（屏幕外渲染）+ 修配置键名不匹配
- 用户诉求："还是做不到不浏览器补全静默获取？" → 要的是**浏览器后台静默**，不是完全不要浏览器
  （完全不要浏览器不可能：Argus 对非页面请求一律 403，只有页面自有请求带签名）。
- 静默失败的真正原因：`show:false` 隐藏窗口被 Chromium 判定不可见 → 不渲染/懒加载不触发 → CDP 拦截不到。
- 重构（main.js `collectUserWorksViaBrowser`）：
  - 静默模式不再 `show:false`，改为 **`show:true` + 移到屏幕外 (x/y = -32000) + skipTaskbar + setOpacity(0)**，
    窗口仍参与渲染 → 视口/懒加载/滚动/CDP 拦截照常工作，用户完全看不到窗口。
  - 日志加 `silent=` 与 `kind=` 字段便于验证。
- 兜底（api_client.py `collect_user_post_ids_via_browser`）：静默采集返回空时
  **自动改用可见窗口重试一次**，宁可弹一次窗也不让任务失败（logger.error 可见）。
- **顺带修复配置键名不匹配**：界面 settings.json 用 camelCase `browserFallback`，而 Python 只认
  snake_case `browser_fallback` → 界面"无头/静默"开关此前**完全失效**。
  新增 `_browser_fallback_cfg()`（api_client）兼容两种键名；user_downloader 两处同样改为兼容读法。
- 校验：py_compile（api_client/user_downloader）+ node --check 全过。待用户重启实测。
