## douyin-downloader-main11111：下载原理分析 + 「下载返回空值」修复

### 下载原理（数据流）
1. `cli/main.py` → `core/url_parser.py` 解析链接类型（视频/图文/用户主页/短链）
2. `core/downloader_factory.py` 选择下载器（`VideoDownloader` / `UserDownloader` / `MixDownloader` / `MusicDownloader` / `LiveDownloader`）
3. `core/api_client.py` `DouyinAPIClient`：
   - `_default_query()` 组装设备/浏览器指纹参数 + `msToken` + `uifid`
   - `build_signed_path()` → a_bogus（优先）或 X-Bogus 签名
   - `_request_json()` 发请求；**任何失败（403/非JSON/重试耗尽）一律静默返回 `{}`**
   - `_normalize_paged_response()` 规范化分页（items/has_more/max_cursor/status_code/risk_flags/raw）
4. `core/user_modes/*_strategy.py` 按模式分页抓取：post 有完整策略；like/mix/music 走基类 `_collect_paged_aweme`
5. `downloader_base._download_aweme_assets()` → `_detect_media_type` → `_build_no_watermark_url()` 选 play_addr → `file_manager.download_file()` 落盘
6. `storage/` 写元数据、`download_manifest.jsonl`、SQLite

### 「下载返回空值」根因（已复现）
`_request_json` 被 Argus 403 时静默返回 `{}`，`_normalize_paged_response({})` 得到
`items=[]` 且 `raw={}`（无任何状态字段）。基类 `_collect_paged_aweme` 的
`if not page_items: break` **不区分「接口失败」与「真的 0 作品」**，直接返回 `[]`：
- `post` 模式：有诊断 + 浏览器兜底 + 抛 RuntimeError（行为正确）
- `like` / `mix` / `music`：静默返回 `[]`，**无任何提示、无兜底** ← 这就是「返回空值」

第二处空值：`file_manager.download_file` 遇到 HTTP 200 + 空 body 时，若
`expected_size` 为 None（无 Content-Length）或 0，长度校验被跳过，
会**写入 0 字节文件并报成功**。

### 修复
1. `core/user_modes/base_strategy.py`
   - 新增 `_is_blocked_empty_response()`：靠 `raw` 是否为空/缺状态字段区分「被风控」与「真 0 作品」
   - 新增 `_blocked_diagnostic()`（登录态失效 / 验证码 / 风控空响应）与 `_try_browser_recovery()`（按模式查找 `_recover_user_{mode}_with_browser`）
   - `_collect_paged_aweme` 首页空且判定为被拦截时：透出诊断 → 尝试浏览器兜底 → 仍空则抛明确 RuntimeError
   - 加 `page_index` 计数，只对首页生效，避免误伤
2. `storage/file_manager.py`
   - `download_file` 增加 `written == 0` 判定 → 判失败并清理 .tmp，不再留 0 字节文件
